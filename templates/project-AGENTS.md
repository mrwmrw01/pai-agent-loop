# Project instructions

This project follows the seven-phase **ISC loop** (PAI Algorithm) by default.

For any non-trivial task, load `/skill:isc-loop` (OBSERVE → THINK → PLAN → BUILD → EXECUTE →
VERIFY → LEARN) and track work in an ISA via `/skill:isa`. Classify first — MINIMAL / NATIVE
prompts (greeting, one fact, one single-line edit, one command) skip the loop. Set depth with
`/e1`–`/e5`. Verify every criterion with real tool output before claiming done.

Persistent spec for this project lives in `ISA.md` at the repo root (create on first substantial
task, E3+ structure). Full directive: `~/AGENTS.md` · skills:
`~/.agents/skills/isc-loop/SKILL.md`, `~/.agents/skills/isa/SKILL.md`.
